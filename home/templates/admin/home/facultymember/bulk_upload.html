How to use the Bulk Upload tool

This tool allows you to upload multiple faculty members at once. You will need to prepare two files: a CSV file containing their information, and a ZIP file containing their photos.

Step 1: Prepare the CSV File

Create an Excel spreadsheet and save it as a .csv (Comma Separated Values) file. Ensure it has the exact following headers in the first row:

📥 Download Sample CSV Template

Column Header Data Type / Format Example
name Text (Required) John Doe
designation Text (Required) Mathematics Teacher
category Must be one of: Administration, Teacher, or Office Staff Teacher
image_filename The exact filename of their photo in the ZIP (including extension). john_doe.jpg

Step 2: Prepare the ZIP File

Place all the faculty photos (e.g. john_doe.jpg, jane_smith.png) into a folder. Right-click the folder and select "Compress" or "Send to Compressed (zipped) folder" to create a .zip file.

Note: Make sure the names of the images inside the ZIP exactly match the image_filename column in your CSV!
